Compiler Design Lab — Execution Guide

18 programs: filenames, compile commands, sample inputs, and expected outputs for Ubuntu

1. Install tools (one time)

sudo apt update
sudo apt install gcc flex bison -y

Create/open your lab folder:
mkdir -p ~/compiler_lab
cd ~/compiler_lab

2. General compilation commands

These commands are valid for Ubuntu/Linux. On macOS with Homebrew Flex, the linker usually cannot find libfl unless you add the Flex library path.

Linux/Ubuntu:
C:                 gcc file.c -o program && ./program
Lex:               flex file.l && gcc lex.yy.c -o program -lfl && ./program
YACC:              bison -dy file.y && gcc y.tab.c -o program -lfl && ./program
Lex + YACC:        bison -dy calc.y && flex calc.l && gcc y.tab.c lex.yy.c -o calc -lfl && ./calc

macOS (Homebrew Flex):
Lex:               flex file.l && gcc lex.yy.c -o program -L/opt/homebrew/opt/flex/lib -lfl && ./program
YACC:              bison -dy file.y && gcc y.tab.c -o program -L/opt/homebrew/opt/flex/lib -lfl && ./program
Lex + YACC:        bison -dy calc.y && flex calc.l && gcc y.tab.c lex.yy.c -o calc -L/opt/homebrew/opt/flex/lib -lfl && ./calc

If your Mac uses Intel Homebrew instead of Apple Silicon, use /usr/local/opt/flex/lib instead of /opt/homebrew/opt/flex/lib.

For interactive Lex programs that keep reading from the keyboard, press Ctrl+D at the start of a new line to send EOF. Programs that request one line may finish when you press Enter.

1. Symbol table

Filename: symbol.c

Commands:
gcc symbol.c -o symbol
./symbol

Example input:
3
 a int
 b float
 sum int

Expected output:
Symbol Table
Name    Type
a       int
b       float
sum     int

Notes: C program stores and displays names and types.

2. Lexical analyzer

Filename: lexer.l

Commands:
flex lexer.l
gcc lex.yy.c -o lexer -lfl
./lexer

Example input:
int total = 25;

Expected output:

Special character: ;

Notes: Press Ctrl+D after input. Recognizes identifiers, integers, operators, // comments and other characters.

Common troubleshooting

• If flex says it cannot open a file, run ls and check the filename and current folder.
• If gcc says lex.yy.c is missing, run flex yourfile.l first.
• If gcc says ld: library 'fl' not found, you are on macOS and need the Homebrew Flex path:
  - Apple Silicon: -L/opt/homebrew/opt/flex/lib -lfl
  - Intel Mac: -L/usr/local/opt/flex/lib -lfl
• For Lex + YACC, run bison -dy calc.y before flex calc.l because calc.l includes y.tab.h.
• If the terminal appears to wait for more input, press Ctrl+D at the start of a new line for keyboard-driven Lex programs.
• Save edited files before compiling again.
